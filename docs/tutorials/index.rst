Tutorials
=========

Welcome to the Katharos tutorials! These step-by-step guides will help you learn functional programming concepts and how to use Katharos effectively.

**Tutorials are learning-oriented.** They take you by the hand through a series of steps to complete a project. Start here if you're new to Katharos or functional programming in Python.

What You'll Learn
-----------------

Through these tutorials, you'll learn:

- How to install and set up Katharos
- The basics of functional programming with algebraic types
- How to work with Maybe and Result for safe error handling
- How to compose operations using Functors and Monads
- How to use immutable data structures effectively

Prerequisites
-------------

These tutorials assume you have:

- Basic Python knowledge (functions, classes, type hints)
- Python 3.13 or later installed
- Familiarity with pip for package installation

No prior functional programming experience is required!
